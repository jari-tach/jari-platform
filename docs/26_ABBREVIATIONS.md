## الاختصارات

| الاختصار | التعريض الكامل | الوصف |
|----------|----------------|-------|
| **API** | Application Programming Interface | واجهة برمجة التطبيقات |
| **JWT** | JSON Web Token | توكن مصادقة قياسي |
| **SQL** | Structured Query Language | لغة استعلام قاعدة البيانات |
| **CI/CD** | Continuous Integration / Continuous Deployment | التكامل والنشر المستمر |
| **DDD** | Domain-Driven Design | تصميم موجه بالمجال |
| **OTP** | One-Time Password | كلمة مرور مرة واحدة |
| **GPS** | Global Positioning System | نظام الموقع العالمي |
| **ETA** | Estimated Time of Arrival | الوقت المتوقع للوصول |
| **UI** | User Interface | واجهة المستخدم |
| **UX** | User Experience | تجربة المستخدم |
| **SDK** | Software Development Kit | مجموعة أدوات تطوير البرامج |
| **REST** | Representational State Transfer | نمط بنية برمجة التطبيقات |
| **JSON** | JavaScript Object Notation | تنسيق بيانات خفيف |
| **CRUD** | Create, Read, Update, Delete | عمليات إدارة البيانات الأساسية |
